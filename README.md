# 🐉 Магический Дракончик — Telegram Mini App для двоих

Игра, где вы вдвоём растите одного дракончика не один день. Кормите, играйте, укладывайте спать и творите магию — дракон растёт, эволюционирует по стадиям и запоминает, кто о нём заботился.

## ✨ Особенности
- **Общий питомец** — синхронизируется между вами в реальном времени
- **6 стадий эволюции**: Дракончик → Юный → Огненный → Ледяной → Древний → Мифический
- **Реальное течение времени**: голод/настроение/энергия падают со временем; сытый и счастливый дракон набирает XP даже пока вы офлайн
- **6 действий**: Кормить, Играть, Спать, Гладить, Магия (с кулдауном 30 мин)
- **Летопись ухода** — видно, кто что делал и когда
- **Магический визуал**: звёзды, северное сияние, CSS-дракончик с анимациями, спарклы
- **Telegram WebApp SDK**: имя пользователя, haptic feedback, полноэкранный режим

## 🚀 Локальный запуск
```bash
npm install
npm start
# открой http://localhost:3000
```

## ☁️ Деплой на bothost.ru

1. Зайди на https://bothost.ru/dashboard.php и создай новое приложение (Node.js).
2. Загрузи проект (через GitHub-репозиторий или загрузку файлов):
   - `server.js`, `package.json`, папку `public/`
3. Команда запуска: `npm start`
4. Порт bothost передаёт автоматически через `process.env.PORT` — код уже это учитывает.
5. База данных `dragon.db` создастся автоматически при первом запуске.
6. Скопируй выданный публичный URL приложения (например `https://xxxx.bothost.ru`).

> ⚠️ Если bothost поддерживает переменную `DB_PATH` — задай её, направив в постоянную папку (например `/app/data/dragon.db`), чтобы база не терялась при передеплое.

## 🤖 Подключение к Telegram (@BotFather)

1. Открой Telegram → **@BotFather** → `/newbot`, задай имя и username.
2. Получи токен бота.
3. Отправь в @BotFather команду `/newapp` (или `/setmenubutton`), либо:
   - `/setdomain` → выбери бота → укажи домен bothost без `https://` (например `xxxx.bothost.ru`)
4. Для кнопки запуска Mini App:
   - @BotFather → `/setmenubutton` → выбери бота → вставь полный URL `https://xxxx.bothost.ru`
5. Открой бота и нажми кнопку меню — игра откроется внутри Telegram.

## 🎮 Механики
| Действие   | Эффект                         | XP  |
|------------|--------------------------------|-----|
| Кормить    | +22 сытость, +4 энергия        | +6  |
| Играть     | +24 настроение, −12 энергия    | +8  |
| Спать      | +30 энергия, +4 настроение     | +4  |
| Гладить    | +10 настроение                 | +4  |
| Магия 🔮   | +8 всего, кулдаун 30 мин       | +10 |

Статы падают со временем (~4.5/ч голод, ~3.5/ч настроение, ~2/ч энергия). Если дракон сыт и счастлив — он получает +10 XP/час даже офлайн.
